# ClearPath Workbench

ClearPath Workbench helps sales teams build and rehearse demos around what a customer needs to see. Use it to storyboard a focused demo, review the flow, and prepare a draft for Storylane.

## Get started

Open the [Community Preview release](../../releases/tag/community-preview) for the Windows setup and the 2:39 captioned walkthrough.

Download and extract the Windows Setup ZIP. Open the **ClearPath Workbench** folder and double-click **Start Workbench.cmd**.
